# Short description

Keep several Minecraft accounts connected to the same or different servers in one client. Switch players with Z or a vanilla-style selector.

# Description

**Tandem** lets you manage several connected Minecraft players from a single game window.

Join the same server with different accounts or keep sessions open on different Minecraft 26.3 servers. Each player has a separate inventory, position, dimension, game mode, experience, world and HUD. Background sessions keep receiving server updates while you control the selected player.

Press **Z** to cycle through loaded sessions, or open a player selector inspired by Minecraft's **F3 + F4** menu. The selector shows player heads, names and server addresses. Both hotkeys can be reassigned in Controls.

Tandem supports **Fabric and NeoForge**, **Mod Menu** on Fabric, Microsoft accounts through **In-Game Account Switcher**, and offline nicknames for servers with `online-mode=false`. Server-side installation is not required.

Four simultaneous sessions are available by default; the limit can be configured from two to eight. A single account can connect to different servers, while duplicate connections for that account to the same server are prevented.

Client settings and resource packs are shared. Additional server resource-pack requests are declined while multiple sessions are connected, so join servers requiring a pack before adding other sessions. Background players can take damage and are subject to server rules and inactivity limits.

**Minecraft Java 26.3. Java 25. Client-side. Alpha.** Microsoft authentication, secure chat and compatibility with other client mods are experimental.
